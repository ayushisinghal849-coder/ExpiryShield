

# ExpiryShield



### Smart Inventory Management & Expiry Risk Mitigation System



ExpiryShield is a full-stack inventory intelligence platform designed to help retailers monitor product expiry, manage inventory, and reduce expiry-related losses.



## Live Demo



**Frontend:** https://expiry-shield-inky.vercel.app



**Backend API:** https://expiryshield.onrender.com



**API Documentation:** https://expiryshield.onrender.com/docs



## Features



- Inventory Management

- Product Expiry Monitoring

- Expiry Risk Analysis

- Dashboard and Analytics

- Inventory Insights



## Technology Stack



- React.js

- Vite

- Python

- FastAPI

- SQLite
